# Prompt Template

Use this template for efficient coding requests:

1. Goal: What should change.
2. Scope: Exact files or folders.
3. Constraints: Style, performance, compatibility.
4. Verification: Command(s) to run.
5. Output format: Short summary, patch, checklist, etc.

Example:
Goal: Add missing locale keys for feature X.
Scope: [src/locales](src/locales)
Constraints: Keep key parity with [src/locales/en.json](src/locales/en.json); for any horizontal rails or compact chip trays, keep labels single-line and use the shared overflow-aware cue only when it is actually useful.
Verification: `python3 scripts/validate-translation-keys.py`
Output: changed files + validation result.
